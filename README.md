# Equity Valuation Platform

A Python platform for equity valuation, financial statement analysis, statistical modeling, and quantitative investment research.

## Goals

- Download market and financial data
- Analyze company fundamentals
- Calculate intrinsic value
- Perform statistical analysis
- Build an interactive dashboard

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- yfinance
- Git

## About

This project aims to help investors estimate a company's intrinsic value by combining fundamental analysis, financial modeling, and statistical methods. The platform will evolve into a complete equity research tool capable of data collection, valuation, visualization, and quantitative analysis.
